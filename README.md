# KYOTO PLATEAU HACK 2026

## 作品名

**京都を駆け抜けろ — 忍者鉤縄タイムアタック**

▶ **今すぐ遊ぶ：https://kyoto-ninja.kyoto-ninja.workers.dev**（PC の Chrome / Edge、キーボード＋マウス）

デモ動画（1分40秒・自動操縦によるプレイ）：[demo/kyoto-ninja-demo.mp4](demo/kyoto-ninja-demo.mp4)

## 概要（誰の・どんな課題を、どう解決するか）

**誰の**：大学生。

**どんな課題を**：京都の碁盤目の街路や名所どうしの位置関係は、地上を歩いているだけでは分かりにくい。また、PLATEAU の 3D 都市モデルにどんな情報（建物の形・高さ・築年、川、橋など）が入っているかは、触ってみないと実感しにくい。

**どう解決するか**：PLATEAU の京都市 3D 都市モデルをそのまま舞台にしたブラウザゲームにした。プレイヤーは忍者になり、鉤縄を実在の建物に掛けて街を駆け抜け、京都タワーの頂点を越えるまでのタイムを競う。

- 移動の爽快感を入口に、建物の形と高さを使って進路を選ぶうちに街の構造が身につく。
- コースは実距離のまま（七条通 → 鴨川・七条大橋 → 京都駅 → 東寺五重塔 → 京都タワー、約 3.6km）。
- ゴールすると塔の上からの俯瞰に切り替わり、通った軌跡と碁盤目・鴨川・名所の位置関係を見渡せる。
- 狙った建物の築年と用途が画面に出て、1980 年以前（新耐震基準より前）に建った建物は勢いよく突っ込むと崩れる。ただし住まいを崩すとタイムに罰が付く。都市データの属性が遊びのルールになっている。
- 合言葉を入れるとチームを組め、チームランキングでタイムを競える。

## 使用したPLATEAUデータ・オープンデータ

すべて国土交通省 [Project PLATEAU](https://www.mlit.go.jp/plateau/) の京都市 3D 都市モデル（2025 年度）。配信 URL は PLATEAU データカタログ API で取得し、プレイ中に配信サーバーから直接読み込む（データ自体はこのリポジトリに含めていない）。

| データ | 形式 | ゲームでの使い方 |
| --- | --- | --- |
| 建築物モデル（下京区 LOD3、東山区・南区 LOD2、テクスチャ付き） | 3D Tiles | 建物の表示、当たり判定、鉤縄の固定先。京都タワーの高さ（地上 約 131m）もここから実測 |
| 建築物モデルの属性 `bldg:yearOfConstruction` | 3D Tiles のバッチテーブル | 築年の表示と、壊れる建物（1980 年以前）の判定 |
| 建築物モデルの属性 `bldg:usage` | 3D Tiles のバッチテーブル | 用途の表示。住まい（住宅・共同住宅など）を崩すとタイムに +5 秒。ゴール画面に、伝ってきた建物の用途の内訳を出す |
| 土地利用モデル | MVT | 地面の描画。「水面」を川として扱い、落ちると足が遅くなる |
| 道路モデル（LOD1） | MVT | 道路の描画。「橋梁」区間は川の上でも渡れる（七条大橋） |

- 地面の高さは、建物の足元の高さから推定している（京都市の PLATEAU に地形モデルは無いため）。
- PLATEAU 以外のオープンデータは使っていない。

## 使用技術

| 分類 | 内容 |
| --- | --- |
| 描画 | three.js（WebGL） |
| PLATEAU の読み込み | 3d-tiles-renderer（3D Tiles）、@mapbox/vector-tile ＋ pbf（MVT） |
| 当たり判定 | three-mesh-bvh |
| ビルド | esbuild |
| 公開先 | Cloudflare Workers（ゲームの配信＋チーム記録 API。記録は Durable Objects に保存） |
| 開発 | Claude Code（設計・実装・検証） |

## 動かし方

**https://kyoto-ninja.kyoto-ninja.workers.dev** を PC の Chrome か Edge で開くだけ。インストールは不要。

- 建物データは PLATEAU の配信サーバーから読み込む。実写テクスチャ付きのタイルが重く、**初回の読み込みは 1〜2 分かかることがある**（2 回目以降はブラウザのキャッシュが効く）。
- 名前を入れて「出発する」。同じ合言葉を入れた人どうしでチームになる（空欄ならソロ）。
- スマートフォンとゲームパッドは未対応。

| 入力 | 動作 |
| --- | --- |
| W A S D | 走る・空中で向きを変える |
| マウス | 見回す・狙う |
| 左クリック長押し / F | 鉤縄を掛ける。離すと解除して飛ぶ |
| Space | ジャンプ（空中でもあと 2 回）。縄が掛かっている間は巻き取り |
| V | 三人称 ⇄ 一人称 |
| R / Enter | 直前の通過地点へ戻る / 最初からやり直す |

### 自分でデプロイし直す場合

Node.js 18 以上と Cloudflare のアカウントが必要。

```bash
npm install
npx wrangler login
npm run deploy
```

チーム機能の仕様、検証した内容、未対応の点などの詳細は [docs/details.md](docs/details.md) を参照。
